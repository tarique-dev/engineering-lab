# Tarique's Engineering Lab — V1

A tiny static landing page.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Deploy

This can be deployed to Vercel, Cloudflare Pages, GitHub Pages, Netlify, or any static host.

For the first version, no backend, database, or build step is required.
